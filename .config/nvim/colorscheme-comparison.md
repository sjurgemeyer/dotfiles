# Colorscheme feature comparison

Audit of every colorscheme currently registered in `lua/plugins/colorschemes.lua`. Scope: which Neovim plugin highlight groups each theme defines, and whether the upstream repo also ships terminal-emulator configs (Kitty in particular).

## Legend

- `✓` = supported / present
- blank = not present (or nothing meaningful)
- `~` = partial / minimal / commented-out / legacy-only
- **Tree** column: `N` = NvimTree, `B` = NeoTree, `NB` = both
- **Cmp** column: `c` = nvim-cmp only, `b` = blink.cmp only, `cb` = both

## Highlights of the audit

**Tier 1 — broadest plugin coverage (~15+ plugin integrations):**
kanagawa, oasis, paragon, rakis, silkcircuit, jb, everforest, bamboo, sora, farout, chai

**Tier 2 — solid mainstream coverage (Telescope + Tree + GitSigns + Lualine + Cmp):**
slatewave, melange, evergarden, koda, mellifluous, citruszest, midnight, evangelion, hybrid, noctis, ember, thorn, nightly, candyland, oldtale, witchesbrew, terracotta, radium, vesper, gruvbox-baby, everblush, sakura, thematrix, bebop, vhs-era-theme, nightsky, slack, gruvbox-minor, tzfn, heatherfield, black-metal

**Tier 3 — minimal or classic-vim only** (consider whether you want them in the picker):
tender (vimscript-only, no Treesitter), harlequin, starrynight, nisha, vorange, fleet (TS only), nortia-nvim (legacy `TS*`), angelic, truedark, antares, electron-vue-darker, pustota, habamax.nvim (sparse), nightwolf (shallow plugin support), oxide

**Themes with the richest Kitty/terminal-port story:**
- **paragon** (~31 ports — most of any in this set)
- **oasis** (~24+ including kitty, browsers, mail, file managers)
- **silkcircuit** (~19, including 5 terminals + dev-tooling: btop, k9s, lazygit, bat, fzf, atuin, starship, tmux + VS Code + Chrome theme)
- **sora** (~17 — all major terminals + tmux/btop/bat/delta/fzf/lazygit/yazi/zed/obsidian)
- **bamboo** (~15 including kitty, konsole, ptyxis, vivid, vscode, zed)
- **kanagawa** (~17 ports across terminals + window managers + fish/sway/hyprland)
- **farout** (~20 — broad legacy-Linux focus: st, tilix, terminator, xfce, xresources, dunst, zathura)
- **black-metal** ships kitty (and 8 other tool configs) for *each* of 17 sub-themes — likely the highest *file* count of all repos.

**No terminal/external-app port at all (Neovim-only):**
ember, fleet, nightly, sakura, harlequin, candyland, thematrix, habamax.nvim, bebop, nightblossom, nisha, starrynight, vorange, andromeda, nortia-nvim, angelic, truedark, antares, vhs-era-theme, oxide, gruvbox-minor, chai, tzfn, pustota, radium, terracotta, electron-vue-darker, vesper, hybrid, noctis, everblush, evergarden (in-repo).

**Implementation notes worth knowing:**
- `everforest-nvim` is a *Lua port* of the canonical `sainnhe/everforest`; it ships **no** terminal configs of its own. Use the upstream sainnhe repo for terminal ports.
- `vague`, `slatewave`, `posterpole` use a **sister-repo pattern** — each terminal port is a separate GitHub repo under the same org rather than an `extras/` folder.
- `mellifluous` defers to **iTerm2-Color-Schemes** for ports; no in-repo configs.
- `midnight`'s extras are *Lua generators* under `lua/midnight/extras/`, not static `.conf` files.
- `andromeda` highlights **gitgutter + signify** (older git plugins), not GitSigns.
- `nortia-nvim` only defines the deprecated `TS*` group names — won't fully colorize modern treesitter trees.
- `electron-vue-darker` is essentially a lush template with most plugin sections commented out.

## Sources

Source paths inspected (all under `~/.local/share/nvim/lazy/`):
plugin highlights typically live in `lua/<name>/{plugins,groups,integrations,extensions,highlights/integrations}/`.
Terminal ports typically live in `extras/`, `extra/`, or top-level `kitty/`/`alacritty/` directories.
